# Globale preferanser

- Jeg reviewer endringer i nvim (gitsigns + difftool). Hold diffs små og fokuserte;
  ikke reformater kode du ikke ellers endrer.
- Staged endringer er allerede gjennomgått av meg — ikke unstage eller rør dem.
- Commit-meldinger: korte, små bokstaver, norsk (f.eks. "bedre difftool").
- Ikke commit eller push med mindre jeg ber om det.
- Parallelle oppgaver kjøres i egne git worktrees (`<repo>.wt/<branch>`), én agent per worktree.
- Kjør prosjektets egne lint/test-kommandoer før du sier at noe er ferdig.
